# Заявки с сайта → Telegram без своего сервера (Cloudflare Worker)

Проблема: на хостинге по тарифу нельзя развернуть бэкенд на api.sd-kt.ru.
Решение: поддомен вообще не нужен. Бесплатный Cloudflare Worker даёт свой адрес
вида `https://syndicat-relay.<логин>.workers.dev` — 100 000 запросов в день
бесплатно, без карты. Хостинг сайта не трогаем.

Схема двойная и надёжная:
- письмо на m2@sd-kt.ru через formsubmit.co работает как раньше (ничего не ломаем);
- параллельно копия заявки мгновенно прилетает в Telegram-группу через бота
  @syndicatru_bot.

## Шаг 1. Аккаунт Cloudflare (2 минуты)

1. Зайти на https://dash.cloudflare.com/sign-up
2. Зарегистрироваться по email (карта не нужна, тариф Free).

## Шаг 2. Создать воркер (2 минуты)

1. В левом меню: **Workers & Pages** → **Create** → **Create Worker**.
2. Имя: `syndicat-relay` → **Deploy**.
3. Нажать **Edit code**, стереть всё и вставить содержимое файла
   `worker.js` из этой папки → **Deploy** (справа сверху).

## Шаг 3. Добавить токен бота и id группы

1. В воркере: **Settings → Variables and Secrets → Add**.
2. Добавить две переменные (тип **Secret**):
   - `BOT_TOKEN` — токен бота @syndicatru_bot (выдавал @BotFather; если потерялся —
     в @BotFather команда `/mybots` → бот → API Token).
   - `CHAT_ID` — id группы, куда падают заявки. Как узнать:
     бот уже должен быть в группе; отправьте в группу любое сообщение, затем
     откройте в браузере (подставив токен):
     `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
     и найдите `"chat":{"id":-100XXXXXXXXXX` — это отрицательное число и есть CHAT_ID.
     Если ответ пустой — снимите вебхук: `https://api.telegram.org/bot<ТОКЕН>/deleteWebhook`
     и отправьте сообщение в группу ещё раз.
3. **Deploy / Save**.

## Шаг 4. Проверка

В терминале (подставить свой адрес воркера):

```bash
curl -X POST "https://syndicat-relay.ВАШ-ЛОГИН.workers.dev" -d "Имя=Тест" -d "Контакт=+7 900 000-00-00" -d "Запрос=проверка релея"
```

В группе должно появиться сообщение «🔔 Заявка с сайта sd-kt.ru».

## Шаг 5. Подключить сайт

Прислать мне адрес воркера (`https://syndicat-relay….workers.dev`) — я пропишу
его в `index.html` и `catalog.html` (константа `RELAY_URL` уже заготовлена там,
нужно вставить адрес в одну строку) и запушу.

## Примечания

- formsubmit.co остаётся резервным каналом: если воркер вдруг недоступен,
  письмо на почту всё равно уйдёт.
- Позже, когда домен переедет на DNS Cloudflare, воркеру можно бесплатно
  привязать красивый адрес (например api.sd-kt.ru) — но это косметика,
  работать будет и так.
- Токен бота хранится только в секретах Cloudflare, в код сайта и в репозиторий
  он не попадает.
